# Condiciones del código

## Estado

Este repositorio privado no concede actualmente una licencia de software
abierto. La ausencia de un archivo `LICENSE` no equivale a dominio público ni a
una autorización implícita para copiar, modificar, redistribuir o explotar
comercialmente el código.

El código puede ejecutarse y revisarse dentro del proceso académico para el que
fue entregado. Cualquier publicación, reutilización fuera de ese contexto o
cambio a una licencia abierta requiere una decisión expresa de las personas
titulares del proyecto.

## Separación respecto de los datos

Las condiciones de [`DATA_LICENSE.md`](DATA_LICENSE.md) corresponden a los
datos y a sus fuentes. No licencian automáticamente:

- los módulos Python;
- las pruebas;
- la documentación original del proyecto;
- el modelo serializado;
- la presentación ni el informe.

Del mismo modo, una eventual licencia futura del código no puede eliminar las
obligaciones de atribución y uso no comercial de los CSV derivados de PEP725.

## Dependencias

Las dependencias de `requirements.txt` mantienen sus propias licencias. Su
instalación o distribución debe respetar las condiciones publicadas por cada
proyecto. Este documento no modifica esas licencias.

## Decisión pendiente

Si el equipo decide publicar el código o el notebook, debe seleccionar y añadir
una licencia compatible con la estrategia de distribución y revisar por
separado qué datos pueden acompañar esa publicación. No se asignará una
licencia sin la aprobación expresa del equipo.
